# Diskviz

Disk Scheduling Visualizer and Seek Time Analyzer

## About
This project provides a robust visualization tool for analyzing and comparing standard disk scheduling algorithms. It enables users to input custom request queues, observe the mechanical movement of the disk head, and analyze performance metrics in real-time. The application was developed as part of the Operating Systems Lab coursework for the 2025–26 academic year.

## Features
- Real-time animation of disk head movement across tracks
- Support for FCFS, SSTF, SCAN, C-SCAN, LOOK, and C-LOOK algorithms
- Dynamic calculation of total head movement and average seek time
- Visual step-by-step seek path chart mapping the service order
- Side-by-side performance comparison of all algorithms
- Configurable disk parameters including size, initial position, and direction

## Tech Stack
- React
- Vite
- Recharts
- Tailwind CSS
